# HD Turismo

> **Descobrindo a história, a cultura e as belezas naturais do Haiti.**

## 📖 Sobre o projeto

A **HD Turismo** é uma empresa fictícia desenvolvida para um projeto interdisciplinar acadêmico, com o objetivo de apresentar alguns dos principais pontos turísticos do Haiti por meio de uma plataforma web moderna, informativa e responsiva.

O site foi desenvolvido simulando uma agência de turismo digital, permitindo aos usuários conhecer destinos turísticos haitianos, explorar informações históricas, curiosidades e aspectos culturais de cada local apresentado.

Além da divulgação turística, o projeto busca aplicar conhecimentos de desenvolvimento web, design de interfaces, experiência do usuário e responsividade.

---

## 🎯 Objetivos

* Apresentar os principais pontos turísticos do Haiti;
* Divulgar informações históricas, culturais e turísticas;
* Desenvolver uma interface moderna e intuitiva;
* Aplicar conceitos de desenvolvimento front-end;
* Simular o funcionamento de um portal de turismo profissional.

---

## 🌍 Destinos apresentados

* 🏰 Citadelle Laferrière
* 🏛️ Palais Sans-Souci
* 🌊 Bassin Bleu
* 🏖️ Cap-Haïtien
* ⛪ Saut-d'Eau

Cada destino apresenta informações sobre:

* História;
* Curiosidades;
* Importância cultural e turística;
* Galeria de imagens.

---

## ✨ Funcionalidades

* Página inicial com apresentação da HD Turismo;
* Seção **Início**;
* Seção **Destinos**;
* Seção **Sobre Nós**;
* Cards interativos dos destinos turísticos;
* Navegação para páginas individuais de cada destino;
* Informações detalhadas sobre história e curiosidades;
* Botões de navegação e retorno entre páginas;
* Interface moderna e intuitiva;
* Layout responsivo para diferentes dispositivos.

### Executar localmente

1. Clone este repositório:


2. Abra a pasta do projeto no Visual Studio Code.

3. Execute o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server**.
